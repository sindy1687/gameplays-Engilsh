請幫我在商城新增「抽卡券販售功能」。

重點：
不要只做畫面。
玩家購買抽卡券後，抽卡券必須真的增加。
進入抽卡頁時，必須真的可以使用抽卡券抽卡。

========================
【一、商城新增抽卡券商品】
========================

請在商城新增一個分類：

🎫 抽卡券商店

商品內容：

1. 普通抽卡券 x1
售價：⭐100

2. 普通抽卡券 x5
售價：⭐450

3. 普通抽卡券 x10
售價：⭐850

4. 高級抽卡券 x1
售價：⭐300

5. 高級抽卡券 x5
售價：⭐1400

6. 限定抽卡券 x1
售價：⭐500

========================
【二、購買必須真實扣星星】
========================

購買時請檢查玩家星星數量。

如果星星不足：
顯示 Toast：
星星不足，無法購買。

如果星星足夠：
1. 扣除星星
2. 增加抽卡券
3. 更新商城畫面
4. 更新首頁星星
5. 更新抽卡頁抽卡券數量
6. 儲存 localStorage
7. 如果有 Google Sheet，同步玩家資料

禁止只顯示購買成功但資料沒有變。

========================
【三、抽卡券資料必須沿用現有資料】
========================

請先搜尋整個專案是否已有抽卡券欄位，例如：

gachaTickets
drawTickets
ticket
tickets
playerData.gachaTickets
userData.gachaTickets

如果已有，請直接沿用。

如果完全沒有，才新增：

playerData.gachaTickets = {
  normal: 0,
  premium: 0,
  limited: 0
}

禁止新增第二份抽卡券資料。

========================
【四、抽卡頁必須真實連動】
========================

抽卡頁必須讀取同一份抽卡券資料。

普通卡池：
消耗 normal 抽卡券

高級卡池：
消耗 premium 抽卡券

限定卡池：
消耗 limited 抽卡券

如果目前只有一種卡池，先讓所有抽卡券都可用在目前卡池，但要保留日後分池擴充接口。

========================
【五、抽卡時必須真的扣除】
========================

單抽：
扣除 1 張抽卡券。

十連抽：
扣除 10 張抽卡券。

抽卡券不足：
不能抽卡。

顯示 Toast：
抽卡券不足，請先到商城購買或完成任務取得。

========================
【六、抽到卡片必須真的進倉庫】
========================

抽卡成功後：

1. 抽卡券扣除
2. 產生卡片
3. 卡片加入玩家卡片倉庫
4. 更新卡片圖鑑
5. 更新GM卡片管理
6. 更新localStorage
7. 如果有Google Sheet，同步資料

不能只有抽卡結果畫面。

========================
【七、商城購買紀錄】
========================

新增或沿用購買紀錄：

playerData.purchaseHistory

每次購買記錄：

- 日期時間
- 商品名稱
- 抽卡券種類
- 數量
- 花費星星
- 購買後星星
- 購買後抽卡券數量

========================
【八、GM必須可以管理】
========================

GM頁面新增：

抽卡券管理

功能：

1. 查看普通抽卡券
2. 查看高級抽卡券
3. 查看限定抽卡券
4. 增加抽卡券
5. 扣除抽卡券
6. 直接設定抽卡券數量
7. 查看購買紀錄

GM修改後要同步：

首頁
商城
抽卡頁
玩家資料
localStorage
Google Sheet

========================
【九、每日任務與每日簽到連動】
========================

如果每日任務或每日簽到有送抽卡券，也必須增加到同一份抽卡券資料。

禁止每日任務一份抽卡券、商城一份抽卡券、抽卡頁又一份抽卡券。
