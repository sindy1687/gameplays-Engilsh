---
description: 抽卡券稀有度限制系統開發規則 - 不同抽卡券必須真的只能抽到指定稀有度或指定卡池
---

請幫我建立「抽卡券稀有度限制系統」。

重點：
不同抽卡券必須真的只能抽到指定稀有度或指定卡池。
不要只改商品名稱或UI文字。

========================
【一、抽卡券種類規則】
========================

請建立或整合以下抽卡券：

1. 普通抽卡券
用途：
只能抽出 A 卡

規則：
normalTicket 只能抽 rarity === "A"

2. 稀有抽卡券
用途：
只能抽出 R 卡

規則：
rareTicket 只能抽 rarity === "R"

3. 高級抽卡券
用途：
可抽出 R / SR 卡

規則：
premiumTicket 只能抽 rarity === "R" 或 rarity === "SR"

4. SSR抽卡券
用途：
必出 SSR 卡

規則：
ssrTicket 只能抽 rarity === "SSR"

5. 限定抽卡券
用途：
只能抽限定卡池

規則：
limitedTicket 只能抽 poolType === "limited"

6. 主題抽卡券
用途：
只能抽指定系列卡池

例如：
火影忍者抽卡券
可可夜總會抽卡券
星座抽卡券
希臘神祇抽卡券

規則：
themeTicket 只能抽 series === 指定系列

========================
【二、資料欄位】
========================

請先搜尋專案現有抽卡券資料。

如果已有：

playerData.gachaTickets

請擴充成：

playerData.gachaTickets = {
  normal: 0,
  rare: 0,
  premium: 0,
  ssr: 0,
  limited: 0,
  theme: {}
}

theme格式：

theme: {
  "火影忍者": 0,
  "可可夜總會": 0,
  "星座": 0,
  "希臘神祇": 0
}

如果已有其他欄位名稱，請沿用原欄位，不要建立第二份資料。

========================
【三、抽卡頁選券邏輯】
========================

抽卡頁新增：

選擇抽卡券

例如：

🎫 普通抽卡券：5
🎫 稀有抽卡券：2
🎫 高級抽卡券：1
🎫 SSR抽卡券：0
🎫 限定抽卡券：1
🎫 火影忍者抽卡券：3

玩家必須先選擇要使用哪一種抽卡券。

選擇後才可以抽卡。

========================
【四、抽卡池過濾規則】
========================

抽卡時不要直接從全部卡片抽。

必須先依照抽卡券種類過濾卡片。

例如：

使用普通抽卡券：

availableCards = allCards.filter(card => card.rarity === "A")

使用稀有抽卡券：

availableCards = allCards.filter(card => card.rarity === "R")

使用高級抽卡券：

availableCards = allCards.filter(card => card.rarity === "R" || card.rarity === "SR")

使用SSR抽卡券：

availableCards = allCards.filter(card => card.rarity === "SSR")

使用限定抽卡券：

availableCards = allCards.filter(card => card.poolType === "limited")

使用主題抽卡券：

availableCards = allCards.filter(card => card.series === selectedTheme)

========================
【五、保底與必出規則】
========================

如果抽卡券名稱有「必出」，就必須真的必出。

例如：

SSR必出券：

只能從 SSR 卡片抽。

A卡必出券：

只能從 A 卡片抽。

R卡必出券：

只能從 R 卡片抽。

禁止只是提高機率。

========================
【六、抽卡券不足處理】
========================

如果玩家沒有該抽卡券：

不能抽卡。

顯示 Toast：

這張抽卡券不足，請先到商城、每日任務或每日簽到取得。

========================
【七、抽卡成功後扣券】
========================

單抽：

扣除選擇的抽卡券 1 張。

十連抽：

扣除選擇的抽卡券 10 張。

如果不足 10 張：

不能十連抽。

========================
【八、抽卡結果必須符合規則】
========================

抽卡完成後請檢查結果：

使用普通抽卡券：

結果必須全部是 A 卡。

使用稀有抽卡券：

結果必須全部是 R 卡。

使用SSR抽卡券：

結果必須全部是 SSR 卡。

使用主題抽卡券：

結果必須全部是該主題系列。

如果抽出不符合規則的卡片，視為錯誤，請修正抽卡邏輯。

【十、每日任務與每日簽到連動】
========================

每日任務與每日簽到如果送抽卡券，必須指定券種。

例如：

必須真正增加：
